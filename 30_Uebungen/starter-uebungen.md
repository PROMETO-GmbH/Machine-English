# Starter-Übungen (Level 1–2)

Diese Übungen trainieren die Grundtechniken des Prompt Engineerings. Kein Framework nötig, nur Praxis. Alle Beispiele stammen aus dem Alltag technologiegetriebener Unternehmen.

**Zeitbedarf:** ca. 30–40 Minuten für alle Übungen

**Werkzeug:** Teile deinen Bildschirm: GitHub links als Aufgabenblatt, dein KI-Tool rechts zum Arbeiten (ChatGPT, Claude, Microsoft Copilot, Gemini oder ein anderes). Übertrage die Aufgabenstellung per Copy-Paste in das KI-Tool und vergleiche das Ergebnis mit dem Gütekriterium der jeweiligen Übung.

---

## Feedback-Prompt zum Kopieren

Wenn du nicht sicher bist, ob dein Prompt gut ist: Kopiere den folgenden Feedback-Prompt, ersetze die Platzhalter und schicke ihn an dein KI-Tool. Du bekommst eine konkrete Rückmeldung.

```
Bewerte den folgenden Prompt nach diesen 4 Kriterien (je 1–5 Punkte):

1. Kontext: Ist die Situation oder der Hintergrund konkret und ausreichend beschrieben?
2. Aufgabe: Ist klar, was die KI tun soll – eindeutig und spezifisch?
3. Ausgabe: Ist definiert, wie das Ergebnis aussehen soll (Format, Länge, Struktur)?
4. Zielgruppe: Ist erkennbar, für wen das Ergebnis bestimmt ist?

Mein Prompt:
[HIER DEINEN PROMPT EINFÜGEN]

Gib für jedes Kriterium einen Score (1–5) und eine kurze Begründung.
Nenne das stärkste Element und gib einen einzigen konkreten Verbesserungsvorschlag.
```

## Übung 1: Details hinzufügen (10 Min.)

**Aufgabe:** Verbessere diese Level-1-Prompts auf Level 2, indem du Kontext, Branche und konkrete Parameter ergänzt.

| Level 1 (zu vage) | Dein Level-2-Prompt |
|-------------------|---------------------|
| „Was ist MISRA-C?" | _(dein Prompt hier)_ |
| „Wie führe ich ein Mitarbeitergespräch?" | _(dein Prompt hier)_ |
| „Erkläre mir ISO 26262." | _(dein Prompt hier)_ |

**Musterlösung (Beispiel für Zeile 1):**
> „Erkläre MISRA-C einem Embedded-Softwareentwickler, der bisher ausschließlich in C++ auf Linux gearbeitet hat und nun zum ersten Mal in einem Automotive-Projekt nach AUTOSAR Classic entwickelt. Schwerpunkt: die zehn häufigsten Regeln, die erfahrene C++-Entwickler überraschen, mit je einem Code-Beispiel."

---

## Übung 2: Struktur durch Trennzeichen (5 Min.)

**Aufgabe:** Schreibe einen strukturierten Prompt für diese Aufgabe und verwende klare Trennzeichen zwischen Abschnitten:

> *„Analysiere unsere letzte Kunden-Reklamation und erstelle eine Zusammenfassung für die Geschäftsführung."*

Nutze diese Struktur:
```
Aufgabe: [Was soll die KI tun?]
Kontext: [Branche, Produkt, Reklamationsart – kurz beschreiben]
Ausgabe: [Format, Länge, Abschnitte]
Zielgruppe: [Wer liest das Ergebnis?]
```

---

## Übung 3: Schritte anfordern (10 Min.)

**Aufgabe:** Schreibe einen Prompt, der die KI anweist, eine Schritt-für-Schritt-Anleitung zu erstellen. Wähle ein Szenario aus deinem Arbeitsalltag oder eines der folgenden:

- Wie bereite ich ein Design-Review für eine Leiterplatine vor?
- Wie gehe ich beim Onboarding eines neuen Entwicklers vor?
- Wie analysiere ich eine Produktionsstörung strukturiert?

**Hinweise:**
- Benenne Branche und Anlass konkret
- Lege Start- und Endpunkt des Prozesses fest
- Fordere eine bestimmte Anzahl von Schritten an

---

## Übung 4: Persona zuweisen (10 Min.)

**Aufgabe:** Du willst die KI als Sparringspartner für eine schwierige Situation nutzen. Schreibe einen Prompt, der:
- Der KI eine realistische Fachpersona gibt
- Den Kontext klar beschreibt
- Die KI bittet, eine Simulation oder Analyse durchzuführen

Mögliche Szenarien:
- Die KI als erfahrener Lieferantenauditor bewertet euren Beschaffungsprozess
- Die KI als Senior QM-Ingenieur kommentiert eure Fehler-Ursachen-Liste
- Die KI als Betriebsrat-Vertreter antizipiert Einwände zu einer geplanten Maßnahme

**Bonusaufgabe:** Führe das Gespräch tatsächlich durch und notiere, was überraschend gut oder schlecht funktioniert hat.

---

## Selbstcheck: Wie gut war mein Prompt?

| Kriterium | ✅ Ja | ⚠️ Teilweise | ❌ Nein |
|-----------|------|------------|--------|
| Enthält einen konkreten Kontext (Branche, Produkt, Situation) | | | |
| Gibt eine klare, spezifische Aufgabe vor | | | |
| Spezifiziert Format oder Länge der Antwort | | | |
| Vermeidet vage Begriffe wie „gut", „hilfreich", „ausreichend" | | | |
| Wäre für einen fachfremden Kollegen eindeutig verständlich | | | |

Mehr als 2 ❌: Überarbeite den Prompt und probiere es erneut. Ein guter Prompt ist selten beim ersten Versuch fertig.
