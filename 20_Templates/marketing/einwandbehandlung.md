# Template: Einwandbehandlung im Vertrieb

**Framework:** AIM | **Level:** 4 | **Bereich:** Vertrieb

---

## Template (zum Ausfüllen)

```
ACTOR: Du bist ein erfahrener B2B-Vertriebscoach mit Spezialisierung
auf [BRANCHE]. Du kennst die typischen Einwände und weißt, wie man
sie sachlich, überzeugend und ohne Druck behandelt.

INPUT:
- Produkt/Dienstleistung: [z. B. "Cloud-Software für Qualitätsmanagement"]
- Zielkunde: [z. B. "Produktionsleiter, 100–500 MA, DACH"]
- Einwand: [z. B. "Das ist zu teuer" / "Wir haben schon eine Lösung" /
  "Jetzt ist kein guter Zeitpunkt"]
- Unser Alleinstellungsmerkmal: [z. B. "Einzige Lösung ohne IT-Projekt
  realisierbar"]
- Ton: [z. B. "Sachlich, empathisch, lösungsorientiert"]

MISSION: Erstelle 3 verschiedene Reaktionsmöglichkeiten auf diesen
Einwand. Jede Variante soll:
- Den Einwand ernst nehmen (keine Minimierung)
- Eine sachliche Gegenperspektive bieten
- Mit einer offenen Frage enden, die das Gespräch am Laufen hält
Bewerte jede Variante kurz (Wann ist sie am besten geeignet?).
```

---

## Ausgefülltes Beispiel: Preis-Einwand bei SaaS

```
ACTOR: Du bist ein erfahrener B2B-Vertriebscoach mit Spezialisierung
auf SaaS und Industriesoftware.

INPUT:
- Produkt: Cloud-basierte Qualitätsmanagement-Software
- Zielkunde: Produktionsleiter, 50–500 MA
- Einwand: "Das ist zu teuer. Wir haben dieses Budget nicht."
- USP: Keine IT-Ressourcen nötig, Integration in 2 Wochen
- Ton: Sachlich, empathisch, auf Augenhöhe

MISSION: Erstelle 3 Reaktionsmöglichkeiten auf den Preis-Einwand.
Jede Variante nimmt den Einwand ernst, bietet eine Gegenperspektive
und endet mit einer offenen Frage.
```

## Häufige Einwände im B2B (Quickstart)

Ersetze einfach den Einwand im Template:

| Einwand                                            | Kategorie            |
| -------------------------------------------------- | -------------------- |
| „Das ist zu teuer."                                | Preis                |
| „Wir haben schon eine Lösung."                     | Status quo           |
| „Jetzt ist kein guter Zeitpunkt."                  | Timing               |
| „Ich muss das erst intern abstimmen."              | Entscheidungsprozess |
| „Ich brauche mehr Referenzen aus unserer Branche." | Vertrauen            |
| „Das Risiko ist uns zu hoch."                      | Sicherheit           |
